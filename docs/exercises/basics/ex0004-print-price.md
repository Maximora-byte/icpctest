**题目：**定义一个 `double` 变量 `price`，初始化为 `9.9`，使用 `cout` 的默认格式输出它，不额外设置小数位数。

- 输入：无。
- 输出要求：输出变量的默认文本表示，末尾不输出换行符。
- 知识点：浮点数变量、小数字面量、数值与显示格式的区别。

**先想一想：**当前输出是 `9.9` 还是 `9.90`？变量类型是 `double`，是否就会自动保留两位小数？

<details>
<summary>展开参考输出、提示与易错点</summary>

参考输出：

```text
9.9
```

- 现有程序没有设置 `fixed` 或 `setprecision`，不会主动补成两位小数。
- `double` 通常不能精确表示所有十进制小数。屏幕显示 `9.9`，不意味着底层存储的数值一定精确等于十进制的 `9.9`。
- 如果练习要求固定两位小数，可以包含 `<iomanip>`，再使用 `cout << fixed << setprecision(2) << price;`。
- 仅使用 `setprecision(2)` 而不配合 `fixed` 时，在默认浮点格式下控制的是有效数字位数，而非小数点后两位。

</details>
