**题目：**按顺序执行下面四组整型变量操作，手算每一组操作后的变量值，再编写程序输出结果。**每组开始时都重新设置变量，不能把上一组结果带入下一组。**

| 组别 | 本组初始赋值 | 接着执行的表达式 | 输出哪些变量 |
| :--- | :--- | :--- | :--- |
| 1 | `i = 7; j = 8;` | `i *= j + 1;` | `i`、`j` |
| 2 | `i = j = k = 1;` | `i += j += k;` | `i`、`j`、`k` |
| 3 | `i = 1; j = 2; k = 3;` | `i -= j -= k;` | `i`、`j`、`k` |
| 4 | `i = 2; j = 1; k = 0;` | `i *= j *= k;` | `i`、`j`、`k` |

- 输入：无。
- 输出要求：共四行。第一行格式为 `i=值,j=值`，后三行格式为 `i=值,j=值,k=值`；使用英文逗号，不加空格，每行末尾都有换行符。
- 知识点：连续赋值、复合赋值、运算符优先级和结合性、`printf` 的 `%d` 与 `\n`。

**先想一想：**

1. `i *= j + 1` 是把 `i` 乘以 `j + 1`，还是先乘 `j` 再加 `1`？
2. `i += j += k` 应如何加括号？外层使用的是 `j` 的旧值还是更新后的值？
3. 第三组的 `j` 会变成负数吗？第四组中 `k = 0` 会怎样影响结果？

<details>
<summary>展开完整输出与逐步推导</summary>

参考输出：

```text
i=63,j=8
i=3,j=2,k=1
i=2,j=-1,k=3
i=0,j=0,k=0
```

**第 1 组：**`i *= (j + 1)`，所以 `i = 7 × (8 + 1) = 63`，`j` 仍为 `8`。不要算成 `7 × 8 + 1`。

**第 2 组：**`i = j = k = 1` 使三个变量都成为 `1`。复合赋值按右结合分组：`i += (j += k)`。内层将 `j` 变为 `2`，外层把更新后的 `j` 加到 `i`，得到 `i = 3`；`k` 仍为 `1`。

**第 3 组：**`i -= (j -= k)`。内层得到 `j = 2 - 3 = -1`；外层得到 `i = 1 - (-1) = 2`；`k` 仍为 `3`。

**第 4 组：**`i *= (j *= k)`。内层得到 `j = 1 × 0 = 0`；外层得到 `i = 2 × 0 = 0`；`k` 仍为 `0`。

这里的讲解针对 C++17 下的这些具体表达式。「右结合」描述的是表达式如何分组，不应推广成所有表达式都按从右到左的顺序求值。

</details>

<details>
<summary>展开易错点与更清晰的写法</summary>

- 对这里的简单整型变量，可以用 `i = i * (j + 1)` 理解 `i *= j + 1`。对带副作用的复杂左操作数，不要直接机械替换：复合赋值只对左操作数求值一次。
- 为了更容易检查，第二组的核心操作可拆成 `j += k;` 然后 `i += j;`；第三、四组可用同样方法拆开。
- 第一组没有初始化 `k`，也没有读取或输出它；不要自行在第一行追加 `k`。第二组会先给 `k` 赋值再使用。
- `%d` 在这里对应 `int`。保持格式串和参数顺序一致，避免把 `i`、`j`、`k` 打印错位。
- 原文件虽然使用 `<stdio.h>` 和 `printf`，扩展名仍是 `.cpp`；按仓库的 C++17 命令单独编译。

</details>
