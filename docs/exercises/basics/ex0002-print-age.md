**题目：**定义一个名为 `age` 的整型变量，将它初始化为 `18`，然后输出这个变量的值。不要直接把输出语句写成固定字符串 `"18"`。

- 输入：无。
- 输出要求：仅输出变量的值，末尾不输出换行符。
- 知识点：变量声明、`int`、初始化、变量名和值的区别。

**先想一想：**`cout << age;` 和 `cout << "age";` 的输出有什么区别？把初始化值改为 `19` 后，输出语句还需要改吗？

<details>
<summary>展开参考输出、提示与易错点</summary>

参考输出：

```text
18
```

- `int age = 18;` 声明并初始化变量；`cout << age;` 读取变量的值。
- `cout << "age";` 输出三个字母 `age`。
- 初始化值改为 `19` 后，`cout << age;` 会输出 `19`，不用修改输出语句。
- 局部整型变量应先初始化或成功赋值，再读取；不要练习成 `int age; cout << age;`。

</details>
