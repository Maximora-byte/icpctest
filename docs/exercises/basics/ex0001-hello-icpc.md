**题目：**编写一个 C++ 程序，向标准输出写出 `Hello ICPC`。大小写和中间的一个空格都要一致，不添加引号或其他提示文字。

- 输入：无。
- 输出要求：仅输出题目指定的文本。现有源码末尾不输出换行符。
- 知识点：`#include <iostream>`、`main()`、字符串字面量、`cout`、`return 0`。

**先想一想：**字符串两侧的双引号会显示出来吗？`return 0` 会把数字 `0` 输出到屏幕吗？

<details>

参考输出：

```text
Hello ICPC
```

代码块展示的是可见内容；现有程序实际输出为 `Hello ICPC`，末尾没有 `\n`。

- `cout << "Hello ICPC";` 输出字符串内容，双引号属于源码语法。
- `return 0;` 表示从 `main()` 正常返回，不产生屏幕输出。
- C++ 语句结尾的分号、字符串内的空格都要注意。
