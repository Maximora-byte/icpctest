**题目：**定义两个整型变量 `a = 10`、`b = 20`。依次输出 `a` 和 `b`，中间不加空格、逗号或换行，也不进行算术运算。

- 输入：无，`10` 和 `20` 已写在源码中。
- 输出要求：两个变量的十进制表示紧挨在一起，末尾不输出换行符。
- 知识点：多个变量、顺序执行、连续输出、分隔符。

**先想一想：**执行两次 `cout` 会自动换行吗？这个程序会输出 `30` 吗？

<details>
<summary>展开参考输出、提示与易错点</summary>

参考输出：

```text
1020
```

- 第一次输出 `10`，第二次紧接着输出 `20`，因此屏幕显示 `1020`。
- `cout << a; cout << b;` 不会自动添加空格或换行。
- `cout << a << b;` 对这里的两个整数具有相同的可见输出；`cout << a + b;` 才会计算并输出两数之和 `30`。
- 原文件名为 `ab.cpp`；对应的现有练习内容是连续输出。

</details>
