# 分类习题总目录

这里收录与仓库源码对应的复习题，按「总目录 → 知识点分类 → 独立题目」组织。每道题保留一个正文文件，用稳定编号和标签交叉检索，题目增多后无需把所有题面塞进一页。

**当前范围：**5 道 C++ 基础练习。题面根据现有源码整理，尚未确认原始题库与题号；不能据此推断比赛来源或在线评测通过状态。原程序全部使用固定数据、没有标准输入。各题标为「未实现」的拓展练习仅供复习。

## 编号与维护约定

1. **稳定编号：**使用全库唯一编号 `EX0001`、`EX0002`……，不把类别或难度编码进编号。当前已使用 EX0001–EX0005；新增前搜索已有编号，下一号从 EX0006 开始。题目移动分类时保留编号，不将旧编号分配给另一道题。
2. **文件路径：**题目文档采用 `<主分类>/ex编号-英文短标题.md`，例如 [EX0001](basics/ex0001-hello-icpc.md)。每个分类用自己的 `README.md` 维护二级知识点和题目索引。
3. **一题一份正文：**一道题可以有多个标签、解法或语言实现，都在同一题目页登记。独立成题的拓展练习再分配新编号，并与原题互相链接。
4. **元信息保持一致：**题目页记录主分类、难度、标签、来源、实现状态和源码链接。难度「入门 / 基础 / 进阶 / 挑战」是仓库内的学习分级，不冒充平台评分。未知来源写「未确认」，没有验证的通过状态不写「已通过」。
5. **分类逐步细化：**先使用分类页的二级标题。题数增多、索引不易浏览时，再拆二级分类页或子目录，并更新全部链接；不要为尚未收录的题提前铺设大量空目录。
6. **标签复用：**优先复用分类页已有标签；出现新知识点再新增。标签描述知识点，不重复记录语言、难度和实现状态。
7. **源码命名：**源码使用描述题目行为或算法的英文 `snake_case` 名称，保持每题独立编译。原有数字名、缩写名的对应关系见 [重命名对照](basics/README.md#源码重命名对照)。

## 新增一道题

1. 选择主分类与未使用的 EX 编号，复制 [题目模板](TEMPLATE.md) 到对应分类目录。
2. 填写题目、真实输入输出约定、样例、知识点、折叠提示与答案。将推断或自拟内容明确标注；不要给固定数据演示补造原题输入。
3. 登记源码链接、难度、标签与来源；用对应源码或实际题面逐项核对，按题目要求编译并测试样例和边界情况。
4. 更新分类索引；新建主分类时再更新本页。若重命名或移动文件，同时修正 README、题目页、编译示例和其他引用。
