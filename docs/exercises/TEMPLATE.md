# EX编号 题目标题

<!-- 复制到所属分类目录后替换所有占位项，删除这些说明，并核对相对链接。模板不计入已收录题数。 -->

- 导航：填写分类索引与习题总目录的相对链接。
- 主分类：填写主分类 / 二级知识点。
- 难度：入门 / 基础 / 进阶 / 挑战（本仓库学习分级，保留一项）。
- 标签：优先复用已有知识点标签。
- 题面来源：填写可验证的原题链接和题号；未知时写「根据源码整理，原始题库与题号未确认」。
- 实现状态：如「固定数据演示，无标准输入」「已实现，样例已验证」；未验证不要声称通过评测。
- 对应源码：填写实际文件链接；存在多种解法或语言时分别列出。
- 原文件名：仅重命名过的题目需要填写。

## 题目

说明要完成什么任务。根据代码推断、为复习自拟或直接引用原题时，分别标明来源性质，不把推断写成原题要求。

## 输入与输出

- 输入：写清读取方式、字段、组数与数据范围；无输入时明确写「无」，并列出源码固定数据。
- 输出：写清含义、顺序、分隔符、小数位和换行要求。
- 样例：有输入时成对列出输入与输出，并解释必要细节；无输入时只列参考输出。读代码推导类习题可将参考输出放入下方折叠区域。

## 复习问题

列出本题要掌握的知识点，提出一至三个可以自测理解程度的问题。

<summary>展开提示</summary>

</details>

<details>
<summary>展开参考输出与思路</summary>

</details>

## 易错点与复杂度

- 列出真实相关的边界、格式、溢出或实现风险。
- 写明时间与额外空间复杂度；使用 `n` 等符号时解释其含义。
- 区分已经测试的情况与建议自行测试的情况。

## 拓展练习

没有拓展需求时删除本节。若保留，明确标注「未实现」或填写对应实现链接，单独说明新增输入输出约定。拓展题独立收录时分配新 EX 编号，链接过去，不复制一份长期维护的正文。
